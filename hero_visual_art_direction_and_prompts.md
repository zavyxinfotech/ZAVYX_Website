## 1. Executive Summary & Creative Vision

ZAVYX Infotech requires a cohesive, state-of-the-art visual design language across all website pages. Rather than using disconnected stock imagery or generic AI graphics, every hero background belongs to **one unified visual universe**.

### Core Art Direction Identity:
> **"One technology partner with one visual language and multiple specialized digital capabilities."**

* **Aesthetic Tone:** Premium + Futuristic + Corporate + Technical + Innovative + Sophisticated.
* **Format & Aspect Ratio:** 16:9 Cinematic composition optimized for CSS `background-image` and `object-fit: cover`.
* **Clean Text Space:** Strict **40/60 Asymmetric Layout** (Left 40% empty/soft background reserved for HTML typography & CTAs; Right 60% high-detail 3D focal subject).
* **Text & Logo Ban:** 0% embedded text, 0% embedded logos inside the image renders. All typography is rendered cleanly via HTML/CSS.

---

## 2. Reference Image Analysis & Strategic Adaptation

### Analysis of the Reference Image:
1. **Asymmetric Composition:** The primary subject is offset to the right 60% of the frame, leaving the left 40% completely uncluttered for white text, badges, and primary action buttons.
2. **Halo / Arc Node Array:** A circular glass UI arc radiates around the back of the right-side subject, framing the focal point and giving structural depth without spilling into the text field.
3. **Cinematic Studio Lighting:** Direct key light highlights metallic and glass textures, while volumetric rim lighting separates the subject from a deep slate-blue background.
4. **Subtle Gradient Background:** The left-hand side features soft wave curves and subtle ambient gradient glows, maintaining visual interest without impairing text legibility.

```
+------------------------------------------+------------------------------------------+
|  LEFT 40%: TEXT & CTA ZONE              |  RIGHT 60%: 3D FOCAL SUBJECT & HALO ARC |
|                                          |                                          |
|  [ Badge / Category Pill ]               |                  .---.                   |
|                                          |                 /  .  \   [Glass UI Arc] |
|  # Hero Headline Text                    |                |  (O)  |                  |
|  Descriptive Subtitle Paragraph          |                 \  '  /   [3D Subject]   |
|                                          |                  '---'                   |
|  [ Primary CTA ]   [ Secondary CTA ]     |                /_______/                 |
|                                          |                                          |
+------------------------------------------+------------------------------------------+
```

### Strategic Rules — What to Adapt vs. What to Avoid:

| Keep & Adapt (Design Principles) | DO NOT Copy / Avoid |
| :--- | :--- |
| **40/60 Asymmetric Split** (Text Left, Visual Right) | **Copypasting the blue mono color palette** (Use ZAVYX colors) |
| **Curved UI Halo Ring** behind focal subject | **Cliché Robot Head / Humanoid AI face** |
| **Deep Dark Slate Studio Environment** | **Embedded typography, text, or logos inside render** |
| **Frosted Glass & Chrome Materials** | **Generic floating circuit board visuals** |
| **High Negative Space on Left** | **Overly colorful / rainbow gradient fills** |

ZAVYX brand colors must be applied **intentionally and minimally** as lighting accents, glowing node points, and material highlights.

                                  ▼
                             ZAVYX GOLD
                              #F5BF0F
                   (Warm Rim Highlights & Enterprise

### Materiality & Rendering Parameters:
* **Primary Material:** Semi-transparent frosted glass (Glassmorphism) with high refractive index and subtle chromatic dispersion.
* **Secondary Material:** Polished dark gunmetal and brushed chrome structural edges.
* **Lighting:** Dual-point studio lighting with high key contrast, soft volumetric fog, and ambient occlusion shadows.
* **Depth of Field:** Focal point sharp on the right-side 3D subject; subtle gaussian blur on peripheral halo nodes and far background elements.

## 5. Front-End HTML/CSS Integration Guidelines

To guarantee 100% WCAG AAA readability for text placed over these 3D background images, implement the standard ZAVYX Hero CSS overlay system:

```css
/* Standard Hero Background Container */
.hero-section {
  position: relative;
  width: 100%;
  min-height: 85vh;
  background-color: #0b0f19;
  background-image: url('../images/hero_bg_home.png');
  background-size: cover;
  background-position: center right;
  background-repeat: no-repeat;
  display: flex;
  align-items: center;
  overflow: hidden;
}

/* Gradient Overlay for Text Protection */
.hero-section::before {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background: linear-gradient(
    to right,
    rgba(11, 15, 25, 0.95) 0%,
    rgba(11, 15, 25, 0.85) 35%,
    rgba(11, 15, 25, 0.4) 65%,
    rgba(11, 15, 25, 0.15) 100%
  );
  z-index: 1;
}

/* Hero Content Container */
.hero-container {
  position: relative;
  z-index: 2;
  max-width: 1280px;
  margin: 0 auto;
  padding: 0 2rem;
  display: grid;
  grid-template-columns: 5fr 7fr; /* 40/60 Asymmetric Split */
  gap: 2rem;
  align-items: center;
}

/* Mobile & Tablet Responsiveness */
@media (max-width: 991px) {
  .hero-section {
    background-position: center center;
  }
  .hero-section::before {
    background: linear-gradient(
      to bottom,
      rgba(11, 15, 25, 0.92) 0%,
      rgba(11, 15, 25, 0.75) 60%,
      rgba(11, 15, 25, 0.9) 100%
    );
  }
  .hero-container {
    grid-template-columns: 1fr;
    text-align: center;
  }
}
```
